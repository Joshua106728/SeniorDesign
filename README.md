Aimed at helping composers and music learners transcribe music, Ear2Ink is a portable embedded system designed to convert acoustic guitar performances into MIDI files in real time. The device captures audio through a digital microphone, processes the signals on a microcontroller, and stores the resulting data on an SD card for sheet music generation. A keypad interface allows the user to start and stop recordings, and an LCD screen provides system feedback. By combining real-time audio processing with intuitive user interfacing, Ear2Ink offers musicians the freedom to transcribe and compose on the fly.
